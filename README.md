A Node 22 program that writes the funniest thing a talking elevator would say — in the elevator's own voice — to `/output/entry.txt`. The line plays on the elevator's weight limit: it flashes OVERLOAD at 1,000 kilos, Dave squeezes in anyway, and the elevator stops between floors and lets gravity do the talking. One line, 115 characters, first person throughout.

## Run it

```sh
node main.ts
```
